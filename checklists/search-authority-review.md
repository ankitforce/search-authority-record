# Search Authority Review

- [ ] The agent role and search purpose are specific.
- [ ] Allowed source types and prohibited data are stated.
- [ ] The maximum result use is explicit: inform, draft, recommend, or execute with approval.
- [ ] Every material claim keeps a URL and retrieval timestamp.
- [ ] A named owner can review exceptions and conflicting sources.
- [ ] A correction route and retention choice exist.
- [ ] No credentials, customer data, or hidden private context are in the record.
